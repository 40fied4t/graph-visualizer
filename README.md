# Graph visualizer

### Description

This project was done as part of the course TDT4102 at Norwegian University of Science and Technology (NTNU). It was done with the intention of learning syntax primarily, and is thus spaghetti code through and through, and does not serve as a good representation of object oriented programming. It does not use any efficient algorithms, but is fast enough for small graphs. It is therefore a minimum viable program for visualising graphs.

### Controls 

double Lclick -> create node connected to currently hovered node
ctrl + double LClick -> create node connected by directional edge to currently hovered node.

PLUS -> add new node
Rclick -> Select node
E -> add edges between selected nodes

double rClick -> get pathlength to the next node you Select
a -> create directed edge to next node you Select

number keys -> Added edge will have weight according to digit pressed
